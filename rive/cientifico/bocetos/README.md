# Bocetos del personaje (estilo dibujo animado)

Iteraciones estáticas del científico con línea de contorno y proporciones
altas, pensadas para reemplazar al personaje actual de Rive cuando el dibujo
convenza. Están en SVG para poder ajustarlos y, al aprobarse, pasarlos pieza
por pieza a `generar.mjs`.

- `boceto-1.svg`: primera versión, expresión cínica.
- `boceto-2.svg`: más loco, pelo con más volumen, camisa celeste, pantalón marrón.
- `boceto-3.svg`: pelo barrido, manos con dedos, cuello levantado, bolsillo.

Estado: en pausa, pendiente de más vueltas con Fermín.
